Run `bench_all.sh` to create the benchmark results for all tools.

Make sure your system is idle before running the benchmark.



**Requirements**:
 - download (and compile) all dependent programs and make their executables available in PATH (see paper for details)

We provide a standalone C\texttt{++ implementation of Wild-AC (v1.0) at https://github.com/Wild-AC/Wild-AC.

Our C\texttt{++ implementation of WuManber (v1.0) is heavily based on code by Ray Burkholder\footnote{https://blog.raymond.burkholder.net/index.php?/archives/362-C++-Implementation-of-Wu-Manbers-Multi-Pattern-Search-Algorithm.html and available at 
https://github.com/Wild-AC/WuManber.

A C++ implementation of the FM-Index by Gottlieb, which was used in our benchmarks is available at https://github.com/Wild-AC/FM-Index.

ProteoMapper (v1.6), last updated 3/3/2023, was downloaded from http://tppms.org/pm/.

PeptideMapper (v5.1.9) was obtained from the Compomics suite at http://genesis.ugent.be/maven2/com/compomics/utilities/5.1.9/utilities-5.1.9.zip.
